# Discover レポート {#discover-reporting}

[!UICONTROL &#x200B; ユーザー設定]内で、ユーザーは通貨をデフォルト通貨からリストされている企業通貨のいずれかに変更するオプションを利用できます。 これにより、3文字の通貨コードと一緒に、コスト、収益、パイプライン収益などの金額の表示が変更されます。
