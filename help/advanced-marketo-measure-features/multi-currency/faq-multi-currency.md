# よくある質問（多通貨） {#faq-multi-currency}

**有効にする機能ビットを確認するにはどうすればよいですか？**

この機能には2つの異なる機能ビットがあることに注意してください。 両方は、「設定：複数の通貨」および「詳細通貨」の「CRM」セクションの「[!UICONTROL 一般]」タブにあります。 お客様が複数の通貨を使用している場合は、複数の通貨を有効にする必要があります。一方、追加機能ビットの高度な通貨は、お客様が[!DNL Salesforce]の「高度な通貨管理」機能を使用し、ユーザーがコンバージョン率の時間ベースの範囲を設定できる場合に有効にすることができます。

Marketo Measureは、顧客のCRMから通貨設定を自動的に取得します。 CRMに合わせてMarketo Measureを手動で設定する必要はなくなりました。 通貨設定は、「CRM」の「一般」ページにあります。

**広告アカウントが警告メッセージを表示するのはなぜですか？**

広告アカウントの横に警告メッセージが表示されます。この広告アカウントには、サポートされていない通貨から流入している可能性があります。 この場合、ダッシュボードには「Mixed Currencies」メッセージが表示されたタイルが含まれます。 この不明な通貨にCRMのコンバージョンが含まれていることを確認するには、CRM管理者と連携することをお勧めします。

**ダッシュボードタイルの「混合通貨」の意味は何ですか？**

下部に「Mixed Currencies」メッセージが表示されているタイルがある場合は、認識できない通貨にマッピングされているいくつかのコストをインポートしたことを意味します。 当社のすべてのコンバージョンは、実際のコンバージョン率を持つCRMから来る必要があるため、CRMにこの通貨が欠落していることを意味します。 この不明な通貨にCRMのコンバージョンが含まれていることを確認するには、CRM管理者と連携することをお勧めします。

**無効な通貨によって発生する「混合通貨」エラーを修正するにはどうすればよいですか？**

私たちのシステムは、認識できない通貨を「XXX」に更新します。 無効な通貨を持つ商談を除外するには、「タッチポイント設定」ページで抑制ルールを作成して、「XXX」通貨を持つ商談のタッチポイントを禁止します。 処理が完了したら、既知の通貨についてのみレポートします。

**新しい通貨またはコンバージョン率を追加するにはどうすればよいですか？**

新しい通貨またはコンバージョン率の宣言は、[!DNL Salesforce]または[!DNL Dynamics]でのみ実行できるため、これらの値に関する信頼できる唯一の情報源のみが存在します。 新しい通貨またはコンバージョン率が検出されると、[!DNL Marketo Measure]はその通貨をダウンロードして利用できるようになります。 これらの料金を入力するエリアを提供していません。

**通貨が正しい形式で表示されていません。 どうすれば変更できますか？**

一部の国では、金額のフォーマット方法が異なります（例：1,234.00、1.234、1,234）。 しかし、異なる国や通貨は異なる扱いができるので、ユーザーの通貨を決定するだけでなく、その原産国を決定する必要がある場合は、別のレベルの複雑さを導入します。 選択した一貫した形式は1,234.00です。 これは変更できません。

**選択した通貨の通貨記号を表示できないのはなぜですか？**

[!DNL Salesforce]と[!DNL Dynamics]には、3文字のコンバージョンコードが表示されます。 つまり、一貫性を保つために、変換された金額は、シンボルではなく3文字の変換コードで表示されます。

**複数通貨が有効になっていない場合、顧客にはどのような情報が表示されますか？**

お客様が複数通貨機能を持っていない場合、CRMからデフォルトで通貨ロケールに変更し、企業通貨での支出と収益を示すすべてのISO コードを変更します。 これが正しくなく、お客様が通貨を混在して使用している場合は、複数通貨機能を取得するようにアップグレードすることをお勧めします。

**この機能は、CRMのタッチポイントベースのレポートにどのような影響を与えますか？**

基本的な（高度でない）通貨管理のみを使用する[!DNL Dynamics]および[!DNL Salesforce]のお客様の場合、タッチポイントの売上金額を正しく変換する必要があります。したがって、CRM レポートは期待どおりに機能する必要があります。

残念ながら、[!DNL Salesforce]の長年の制限により、[!DNL Salesforce]の高度な通貨管理のユーザーにとってこれが機能する方法には、いくつかのニュアンスがあります。 「この場合は何をすべきか」という簡単な答えは、基本（つまり、高度でない）の「通貨を管理」タブで定義されている定額料金を使用して収益額を変換することです。 言い換えれば、お客様が日付のある為替レートを定義しているにもかかわらず、日付のある為替レートは完全に無視されます。

興味のある読者のために、これが理由です。 当社の顧客接点では、収益（関連する商談金額から派生）を計算するために数式フィールドを使用します。 [!DNL Salesforce]は、これらの数式計算の通貨変換をネイティブにサポートしていますが、通貨サポートの基本的なフレーバーについてのみサポートしています。 日付の為替レートを参照する数式フィールドを定義することは不可能です。 [!DNL Salesforce]はその機能をサポートしていないため、収益計算で日付レートを参照する方法はありません。これらの日付レートが[!DNL Salesforce]に存在するという事実にもかかわらず（おかしな話ですが、それが機能しています）。

**顧客がワークフローを使用して変換されたフィールドに入力した場合、このフィールドをどのように使用すればよいですか？**

オファーは顧客のコンバージョンを処理するようになったので、ワークフローとカスタムフィールドを削除し、未加工の金額の値をインポートすることをお勧めします。
