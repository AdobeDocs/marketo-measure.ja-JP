# 設定 {#settings}

この機能には、CRMの[!UICONTROL 一般設定] タブにある2つの個別の機能ビットがあります。複数の通貨と高度な通貨です。

**複数の通貨**：お客様が1つ以上の通貨を使用している場合に有効になります。

**Advanced Currencies**：お客様がSalesforceの「Advanced Currency Management」機能を使用し、コンバージョン率の時間ベースの範囲を設定できる場合に有効にする必要がある追加ビット。

[!DNL Marketo Measure] アプリケーションの[!UICONTROL  ユーザー設定]の下に、CRMから引き出された法人通貨とサポート対象の通貨が表示されます。 これらの値はすべてCRMから取得されるため、これらのフィールドは読み取り専用で、変更できません。 ダッシュボードの通貨は、ダッシュボードが読み込まれるたびに使用されるデフォルトの通貨です。 必要に応じて通貨を変更できます。
