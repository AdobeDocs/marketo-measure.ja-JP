# アクティビティアトリビューションに関するよくある質問 {#activities-attribution-faq}

[!DNL Marketo Measure] アクティビティでは、すべてのアクティビティ レコードが読み込まれ、そのタッチポイントが生成されます。これにより、これらのアクティビティでアトリビューション クレジットを受け取ることができます。 最も一般的なユースケースは、セールス部門のアクティビティを追跡することです。通常、見込み客に送信される電話やメールの記録を作成します。 追跡できるその他のユニークな点は、アセットのダウンロードや動画の視聴などのコンテンツのインタラクションです。

>[!AVAILABILITY]
>
>この機能は、Tier 2のお客様に対してのみ有効です。 より高いレベルのアカウントをリクエストするには、Adobe アカウントチーム（担当のアカウントマネージャー）にお問い合わせください。

**これはオフラインキャンペーンとどのように異なりますか？**

最大の違いは、キャンペーンではリードまたは取引先責任者ごとに1人のキャンペーンメンバーしか許可されないため、キャンペーンでは1つのタッチポイントしか提供できないことです。 つまり、アウトバウンドコールやデモ、ウェビナー参加者などの定期的なイベントは、各グループに対して個別のキャンペーンを作成しない限り追跡できません。 アクティビティを使用すると、あらゆるイベントを測定できます。

**タスク、イベント、アクティビティに違いはありますか？**

アクティビティ オブジェクトは、タスク オブジェクトとイベント オブジェクトの上の傘または親として機能します。 アクティビティは基本的に、タスクとイベントの両方をカバーします。 タスクは通常、電話やメールなど、単発のアイテムを簡単に記録するために使用されます。 イベントは通常、ミーティングや会議など、開始日や終了日が設定されているもので使用されます。

**同じ繰り返しタスクを持つリードまたは取引先責任者がいる場合、これらすべてに購入者のタッチポイントが表示されますか？**

はい。 同期したアクティビティとタッチポイントの間に1:1の関係が作成されました。

**作成されたタッチポイントの結果を確認するには、どうすればよいですか？**

まず、CRMのActivity オブジェクトを使用してフィルターを設定することをお勧めします。 フィルタールールに基づいて、その条件に該当するレコードの数を把握し、必要に応じて調整できます。 これは必須ではありませんが、アクティビティ ルールの設定後に作成されるアクティビティ タッチポイントの数をユーザーが把握するのに役立ちます。

**[!DNL Marketo Measure] キャンペーン名は何ですか？**

これらのアクティビティがタッチポイントになるため、[!DNL Marketo Measure]はどのチャネルとサブチャネルに属しているかを把握する必要があります。 各ルールに対して、[!DNL Marketo Measure] キャンペーン名を指定する必要があります。 作成した後、オンラインチャネル CSVを使用して、その[!DNL Marketo Measure] キャンペーン名を適切なチャネルにマッピングします。 [!DNL Marketo Measure] キャンペーン名は、[!UICONTROL 広告キャンペーン名] フィールド内のタッチポイント自体にも表示されます。

**他のどのタッチポイントフィールドに入力されていますか？**

| **タッチポイントフィールド** | **値** |
|---|---|
| リード/コンタクト | すべてのアクティビティは、リードまたは連絡先に関連しています |
| キャンペーン | Channel.Subchannel [[!DNL Marketo Measure]] |
| Touchpoint ソース | CRM アクティビティ |
| 中 | Activity.Type |
| Touchpoint のタイプ | Activity.Type |
| 広告キャンペーン名 | [!DNL Marketo Measure] キャンペーン名 |
| 広告コンテンツ | アクティビティ主体 |
| 広告Id | アクティビティ外部Id |
| Touchpoint の日付 | [ カスタム – アプリで設定] |

**各営業担当者に異なるルールを作成する必要がある場合はどうなりますか？ 各キャンペーンに異なる[!DNL Marketo Measure] キャンペーンを作成する必要がありますか？**

いえ、そんなことはありません。 「Dynamic Campaign Names」を使用すると、Activity オブジェクトからフィールドを参照する「置換パラメーター」を使用して、[!DNL Marketo Measure] キャンペーン名の一部（またはすべて）を入力できます。 例えば、「アウトバウンドコール」というタイトルの[!DNL Marketo Measure] キャンペーン名があり、セールス担当者を最後に配置する場合は、CRM フィールド名を取得し、[!DNL Marketo Measure] キャンペーン名「アウトバウンドコール {AssignedTo}」または「アウトバウンドコール {CreatedBy}」を呼び出します。

**[!DNL Marketo Measure] アプリでアクティビティを設定するにはどうすればよいですか？**

[!UICONTROL Marketo] Measure アプリ内でアクティビティを設定する方法に関する手順については、[!DNL Marketo Measure] アクティビティのサポート記事を参照してください。

**異なる演算子の意味は何ですか？**

* 次と等しい：値と完全に一致（別名：ソーシャル）
* 次を含む：テキストが中央にある（別名：&#42;social&#42;）
* 次で始まる：値はテキストで始まります（別名：social&#42;）
* 次で終わる：値はテキストで終わる（別名：&#42;social）
* 任意の値に一致：複数の値をコンマ区切りで追加できます。 [!UICONTROL が]で始まり、[!UICONTROL が]で終わり、または演算子を含む場合は、ワイルドカード （&#42;）を使用します
* より大きい：数値フィールドまたは日付/時刻フィールドに使用
* 次より小さい：数値フィールドまたは日付/時刻フィールドに使用

**これらのアクティビティはどのチャンネルに属していますか？**

アクティビティルールとそれに対応する[!DNL Marketo Measure] キャンペーン名が作成されたら、オンラインチャネル定義を使用して、それらのキャンペーンを正しいマーケティングチャネルの下に配置します。 [!DNL Marketo Measure]は、メディアとソースだけでなく、キャンペーンも使用してチャネルを定義できます。

上記の例では、「アウトバウンドコール {Assigned To}」キャンペーンをBDR チャネルに割り当てるには、「アウトバウンドコール &#42;」というキャンペーン定義を持つBDR チャネルのオンラインチャネル CSVに行を挿入します。アスタリスクはワイルドカード値を示すため、「アウトバウンドコール」で始まるすべてのキャンペーンは、キャンペーン名ごとに別の行を作成するのではなく、BDR チャネルに該当します。
