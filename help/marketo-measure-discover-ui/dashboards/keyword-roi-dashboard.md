# キーワード ROI ダッシュボード {#keyword-roi-dashboard}

キーワード ROI ダッシュボードでは、有料検索キャンペーンのパフォーマンスに関する詳細なインサイトを提供します。 キーワードレベルのコスト、売上への貢献度、生成された新しいリードや機会などを包括的に分析し、キーワードのROIを明確に把握することができます。

ダッシュボードの質問：

* Google Adwords、Linkedin、Bing Adsの各キーワードのROIはどのくらいですか？
* コストと売上への貢献度を、個々のキーワードごとに示すには、どうすればよいでしょうか？
* 各キーワードから作成されたリードとオポチュニティの数？

## ダッシュボードコンポーネント {#dashboard-components}

### キーワード ROIの概要テーブル {#keyword-roi-summary-table}

個々のキーワードでセグメント化された、売上への貢献度、コスト、ROIを示す表。

特定のキーワードをドリルダウンして、各キーワードの影響を受けた商談を表示します。

**列：**

* **キーワード**
* **キャンペーン**
* **広告アカウント ID**
* **広告アカウント名**
* **広告グループ ID**
* **広告グループ名**
* **コスト**：接続されたデータソースからの合計コスト。
* **属性収益**：選択したアトリビューションモデルに基づく、フィルターされた日付期間内にクローズしたタッチポイントを含む商談からの合計収益貢献度
* **実現済みの属性収益**：選択した属性モデルに基づく、フィルタリングされた日付期間内の顧客接点を持つ商談からの収益貢献度の合計（成約のタイミングに関係なく）。
* **未実現属性のパイプライン収益**：フィルターされた日付期間内に作成されたタッチポイント（オープン商談）にリンクされたパイプライン収益。
* **単純ROI**：フィルタリングされた期間のコストで起因する収益を割った値。
* **実現ROI**：実現された帰属収益を、フィルタリングされた期間のコストで割った値。

### キーワードテーブル別のリードと機会 {#leads-and-opportunities-by-keyword-table}

新しいリード、機会、関連コストを個々のキーワードでセグメント化した表を使用して、詳細な内訳を表示します。

特定のキーワードをドリルダウンして、各キーワードの影響を受けた商談を表示します。

**列：**

* **キーワード**
* **キャンペーン**
* **広告アカウント ID**
* **広告アカウント名**
* **広告グループ ID**
* **広告グループ名**
* **コスト**
* **新規リード**：生成された新規リードの合計数（タッチ済みリードと未操作リードの両方を含む）。
* **新しいリードあたりのコスト**：新しいリードあたりの平均コストで、総コストを新しいリードの総数で割ったものです。
* **新しい商談**：新しい商談が生成された合計数（タッチ済み商談と未操作の商談の両方を含む）。
* **新しい商談あたりのコスト**：新しい商談あたりの平均コストで、総費用を新しい商談の総数で割ったものです。

## フィルターパネル {#filter-pane}

このダッシュボードには、次の設定とフィルターが用意されています。

* 日付
   * 元とするセット：
      * 作成日：ニュースリード、新しい商談
      * コスト発生日：コスト
      * 成約日：売上への貢献度（単純ROI）、案件
      * タッチポイント日：実現済みの帰属済み収益からのタッチポイント（実現ROI）
* アトリビューションモデル
* キーワード
* キャンペーン
