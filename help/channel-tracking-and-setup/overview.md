# 概要 {#overview}

現在、[!DNL Marketo Measure] アプリケーションは1つの通貨（USDと想定）のみをサポートしていますが、当社は、世界中のお客様が独自の会社およびユーザー通貨についてレポートする必要があることを認識しています。 この機能を使用すると、[!DNL Marketo Measure]で報告された支出または売上収益を表示する際に、CRMで使用するのと同じ通貨を切り替えることができます。

## 利用可能性 {#availability}

Tier 2以上。

## 要件 {#requirements}

[!DNL Marketo Measure]は、顧客のCRMから通貨設定を自動的に取得します。 CRMと一致するように[!DNL Marketo Measure]で手動で設定する必要はありません。 通貨設定は、「CRM」の「一般」ページにあります。

[!DNL Salesforce]では、お客様は「複数の通貨を有効化」を有効にする必要があります。 オプションで、お客様は「はい、高度な通貨管理を有効にしたい」を選択することもできます。

Dynamicsでは、顧客は複数の通貨の設定で静的な為替レートを設定できます。 Dynamicsには「高度な通貨管理」という概念はありません。

## 規約 {#terms}

| **条件** | 説明 |
|---|---|
| **高度な通貨** | お客様は高度な通貨管理と複数の通貨を有効にしているため、異なる期間に対して異なるコンバージョン率を持つことができます。 |
| **企業通貨** | CRMの組織によってリストアップおよび宣言される様々な通貨で、コンバージョン率を備えています。 [!DNL Marketo Measure]は、これらの値をインポートし、これらの通貨を製品内のユーザーが利用できるようにします。 |
| **通貨ロケール** | 会社情報ページで設定された、組織に使用される単一の通貨。 |
| **現地通貨（またはユーザー通貨）** | ユーザープロファイルで1人のユーザーに設定された通貨。ユーザーは自分の現地通貨で任意の金額を表示できます。 組織は、ユーザーが現地通貨を選択する前に、通貨を宣言して設定する必要があります。 |
| **単一通貨** | CRMで複数の通貨を使用していないが、組織が別の通貨で実行されているため、「通貨ロケール」を持つ顧客に使用されます。 これはまだ組織にとって単一の通貨ですが、コンバージョンはありません。 |
| **シンプルな通貨** | お客様は複数の通貨を有効にしていますが、通貨ごとの静的コンバージョン率があります。 |
